# Güvenlik Politikası / Security Policy

## Güvenlik Açığı Bildirme

AFN RiskScan CE'de bir güvenlik açığı tespit ettiyseniz, **lütfen public issue açmayın**.

📧 **Doğrudan bize ulaşın:** [info@afnteknoloji.com](mailto:info@afnteknoloji.com)

Konu satırı: `[SECURITY] AfnRiskScan-CE - Kısa açıklama`

### Lütfen bildiride şunları belirtin:
- Açığın türü (örn. komut enjeksiyonu, path traversal)
- Etkilenen versiyon
- Reprodüksiyon adımları
- Olası etki

### Yanıt süremiz:
- **24 saat** içinde alındı onayı
- **7 gün** içinde değerlendirme
- **30 gün** içinde fix (kritiklik durumuna göre daha hızlı)

## Sorumlu Açıklama (Responsible Disclosure)

Açık fix edildikten sonra sizi (izninizle) [CHANGELOG](CHANGELOG.md) ve release notlarında **teşekkürle anacağız**.
