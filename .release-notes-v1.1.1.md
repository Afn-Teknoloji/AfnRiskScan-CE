# v1.1.1 — Güven ve Şeffaflık Sürümü / Trust & Transparency Release

## 🇹🇷 Türkçe

### Yeni

- **Güvenli kurulum akışı.** README artık indir → SHA256 doğrula → kodu oku → çalıştır adımlarını öneriyor. Tek satırlık `irm | iex` komutu duruyor, ancak artık ikinci sırada.

- **Rapor sonu yenilendi.** HTML raporun sonundaki çağrı artık ücretsiz uzman değerlendirmesi: raporunuzu gönderin, bulgularınıza bakıp 1 sayfalık öncelik listesiyle dönelim.

## 🇬🇧 English

### Added

- **Secure installation flow.** The README now recommends download → verify SHA256 → read the code → run. The one-line `irm | iex` command is still there, just no longer first.
- **Data privacy section.** The script sends no data — no telemetry, no analytics, no remote calls. Reports are generated locally.
- **New report call-to-action.** The HTML report now offers a free expert review of your findings instead of a demo request.
